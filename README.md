# PhightingManualAP
a manual APworld for Phighting! on Roblox

if there is a bug please open an issue up on this github or message in the Phighting! (Roblox) forum in the manual apworld server (not the all caps one)

Base items: phighter unlocks

Optional items: ability unlocks

Base locations: map wins with each phighter

Optional locations: post-round badges (mvp/svp/icons which u can hover over), sword events, bonus rounds, multiplier rounds and fractured space, doomsekkar, boomball, phestival titles, skins, stickers, achievements
